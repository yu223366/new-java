# 精灵宝可梦图鉴（PokéDEX）

一个还原动漫原著风格的宝可梦图鉴全栈项目，**收录全国图鉴 1–1025 号全部 1025 只宝可梦**（其中 46 只为动画原著主力，带本地立绘与剧情描述）。**前端可独立运行，也可连接 SpringBoot 后端。**

## 🛡 规则与工程约束

| 约束 | 实现方式 |
|---|---|
| 背包容量上限 | `BAG_MAX = 60`，满包时拦截捕捉并弹提示，防止数据膨胀卡顿 |
| 防重复 | 同一编号不可重复收服；徽章不可重复领取；地区冠军奖励只发放一次 |
| 血量保护 | 伤害结算最低锁定为 0，不会出现负数；胜负判定走独立分支（`over` / `winner`） |
| 图片兜底 | `PokeImg` 组件，任何立绘加载失败自动切换为内置精灵球占位图 |
| 剧情分页 | 原著主线事件每页 4 条、剧场版每页 8 部，避免一次渲染过长文字 |
| 权限提示 | 未解锁的道馆 / 联盟以 Toast 提示，不跳空白页、不报错 |

## ✨ 核心特性：双模式自动切换

| 模式 | 说明 | 需要什么 |
|---|---|---|
| 🟢 **在线模式** | 连接 SpringBoot 后端，数据存 MySQL | Node + 后端 + MySQL |
| 🟡 **本地模式** | 用内置数据 + 浏览器 localStorage，功能完整 | **只需要 Node** |

项目启动时会自动探测后端：
- 后端可用 → 在线模式（右上角显示 `● 在线`）
- 后端没启动 → 自动降级本地模式（右上角显示 `● 本地模式`），**照样能登录、注册、搜索、管理数据**

> 这意味着：把整个项目拷到任何一台装有 Node 的电脑，`npm install && npm run dev` 就能完整使用，不依赖后端和数据库。

## 🚀 快速启动（任何环境通用）

### 环境要求
- **Node.js 16+**（含 npm）—— 唯一必需
- 后端（可选）：Java 17 + Maven + MySQL 8

### 启动步骤
```bash
# 1. 进入项目目录
cd pokemon-vue

# 2. 安装依赖（只需一次，node_modules 丢失时重新执行）
npm install

# 3. 启动
npm run dev
```

浏览器打开终端显示的地址（当前配置为本机局域网 IP `http://192.168.68.29:5173`）。

> 当前前后端已显式绑定到本机 IP `192.168.68.29`（前端 `vite.config.js` 的 `host`、后端 `application.properties` 的 `server.address`），局域网 / 手机可直接用该 IP 访问；绑定后 `localhost` 不再可用。若换机器或 IP 变化，修改 `vite.config.js`、`application.properties` 及 `.env` 中的地址即可；想恢复监听所有网卡，把 `host` 与 `server.address` 改为 `0.0.0.0`。

### Windows 用户（推荐，一键脚本）

双击项目根目录的 **`一键启动.cmd`**，它会自动完成：
1. 探测 MySQL → 启动后端（可选，用于在线模式）
2. 智能定位 Node.js（PATH → 托管版 → DevEco → 常规目录，换机器不用改）
3. 检测 `node_modules`，缺失才安装依赖
4. 后台启动前端并写日志 `_vite.log`
5. 等待前端就绪（最多 2 分钟），自动打开浏览器

单个脚本：`启动-前端.cmd` / `启动-后端.cmd`（可选）；停止：双击 `停止项目.cmd`。

> 这套脚本与 `D:/java_idea/java/java-main` 项目同款（智能探测、幂等、后台日志、假就绪扫描）。
> 想直接看网页？不启后端也行——前端会自动用内置数据（本地模式）。
> AI 启动细节见 `AI-README.md`（GBK 编码的 .cmd 请勿转成 UTF-8）。

## 🔧 常见问题

**Q: 页面能打开但没有数据？**
A: 检查右上角模式标签。本地模式下数据来自内置数据集；若想用真实数据库，请启动后端服务。

**Q: 换电脑后端口冲突？**
A: 修改 `.env` 的 `VITE_PORT`。

**Q: 后端在另一台机器？**
A: 修改 `.env` 的 `VITE_API_TARGET` 为后端地址，如 `http://192.168.1.10:8081`。

**Q: 如何恢复本地演示数据？**
A: 浏览器控制台执行 `localStorage.clear()` 后刷新。
